🔑 Bookmarklet LibreTranslate

Traduit la page Safari courante vers le français via ton instance translate.jefe.ovh.

Note : La clé API complète est 53e04e31-de93-4b49-a0e4-891b1806fc8d (pas juste 53e04e31).

📋 Instructions

  1. Afficher la barre des favoris : Safari iOS → Paramètres → onglets → Afficher la barre des favoris = ON
  2. Créer un favori temporaire : Sur n'importe quelle page, maintiens le bouton Partager → Ajouter aux favoris
  3. Modifier le favori : Va dans les favoris (icône livre), maintiens le favori que tu viens de créer → Modifier
  4. Renommer : Change le titre en 🌐 FR
  5. Coller le code : Remplace l'URL par le code ci-dessous (copie-le en entier)
  6. Sauvegarder → Va sur une page en anglais → tap le favori → la page se traduit
